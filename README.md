# The Haunted Manor

A text adventure set in the old Whitmore Estate.

## Rooms

Each room is described in its own file under `rooms/`.

- `foyer.txt` - The grand entrance
- `library.txt` - Dusty shelves and forgotten tomes
- `ballroom.txt` - Where the music never stopped

## How to Play

Read each room file and piece together what happened to the Whitmore family.
Some say their secrets are still here, if you know where to look.

## Warning

The north wall of the ballroom has been sealed. Do not attempt to open it.
